1. 基础环境：使用 Anaconda 安装了 Python 3.x 环境。
2. 核心依赖库安装：在终端（PowerShell）中执行了以下命令，安装了 PyTorch 及其相关的视觉库：
   ```bash

     pip install torch torchvision torchaudio

   ```

     二. 程序运行方式
3. 确保当前终端的工作目录处于项目的根目录（即 D:\lab_assess）。
4. 在终端中输入并执行以下命令启动训练脚本：
   ```bash

     python task3/mnist_[train.py](http://train.py)

   ```
5. 程序将自动读取数据、构建模型，并在终端打印出每一轮的 Loss 变化以及最终的测试集准确率。
6. 项目所需要的数据文件

本项目使用的是经典的 MNIST 数据集。由于 PyTorch 默认的官方下载链接已失效，本项目采用了手动下载+本地读取的方式准备数据。

· 所需文件列表：

  · train-images-idx3-ubyte.gz (训练集图片)

  · train-labels-idx1-ubyte.gz (训练集标签)

  · t10k-images-idx3-ubyte.gz (测试集图片)

  · t10k-labels-idx1-ubyte.gz (测试集标签)

· 代码处理逻辑：代码中使用了 datasets.MNIST(..., download=True)。在检测到本地 raw 文件夹下已存在这四个完整文件后，程序不会再次尝试联网下载，而是会自动在本地完成解压和数据加载。

**整体实现思路**

1. 数据集内容

MNIST 是一个专门用来练习图像分类的“手写数字图库”。里面的每一张图片都是一张 28×28 像素的灰度图（也就是黑白图），图片的内容是 0 到 9 之间的手写数字。

整个数据集分为两拨：一拨是 60000 张训练集（相当于课本，用来教模型认字）；另一拨是 10000 张测试集（相当于考卷，用来在最后考试，验证模型到底学没学会）。

2. 程序主要执行步骤

整个程序的流程就像教小学生认字一样，分为四个步骤：

1. 数据预处理：程序先把图片读取进来，转化成电脑能算的“数字矩阵”（张量），并做了一个叫“标准化”的操作，把数据统一到相近的范围内，这样能让模型学得更快。
2. 搭建网络（建大脑）：我手动搭建了一个卷积神经网络（CNN）。它有两层“卷积层”，专门用来提取图片里的笔画和轮廓特征；还有两层“池化层”，用来压缩图片大小，减少计算量；最后连着“全连接层”，把提取到的特征汇总起来，判断到底属于 0-9 的哪一个数字。
3. 模型训练（上课）：程序把 60000 张训练图分批（Batch）喂给网络。网络每次猜完后，会跟正确答案对一下，算出一个“损失（Loss）”。如果错得多，损失就大；然后程序通过“反向传播”自动微调网络里的参数。这个过程反复跑了 5 轮（Epoch）。
4. 测试评估（考试）：训练完成后，用剩下没见过的 10000 张测试集图片去考这个模型，最后统计出预测正确的比例，也就是最终的准确率。
5. 容易出错的情况及分析

在真正跑通代码前，我遇到了几个坑：

· 官方下载源失效：PyTorch 默认下载数据的网址（[yann.lecun.com](http://yann.lecun.com)）现在已经打不开了（报 404 错误）。解决办法：我手动从稳定镜像源下载了四个 .gz 压缩包，放到了本地的 ./data/MNIST/raw 文件夹中。

· 找不到数据集：放好文件后，因为代码里设置了 download=False，程序不会自动解压，提示找不到数据。解决办法：把代码里的 download 参数改为 True，程序检测到本地有压缩包，就会自动在后台解压并读取，不需要重新联网。

· 网络超时：下载 PyTorch 库本身时，有时候会遇到网络卡顿或超时，可以通过更换国内镜像源（比如清华源）来解决。
